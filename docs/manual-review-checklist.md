# 人工复核清单

## 目的

本清单用于记录研究过程中需要人工确认的关键关系。

本项目允许使用 AI 辅助候选关系整理、检索关键词生成、代码编写和测试编写，但最终的关系类型、关系方向、证据定位和置信度不直接由 AI 输出决定。

人工复核重点包括：

1. 原始来源是否真实存在且可以公开访问。
2. 来源是否明确支持当前关系类型。
3. 关系方向是否正确。
4. 企业实体是否对应正确，避免同名或上下游主体混淆。
5. customer、partner、deployment relationship 是否被错误混用。
6. evidence locator 是否能够让 reviewer 快速定位原文。
7. confidence 是否与证据强度相匹配。
8. 无法充分确认的关系是否应该降级或排除。

## 人工复核记录规则

完成一条关系的原文核验后，记录：

- 核验日期
- 实际查看的来源
- 关系类型是否保持
- 关系方向是否保持
- evidence locator 是否准确
- confidence 是否需要调整
- 如果修改了 AI 初稿，记录修改原因

只有实际完成原文核验的记录，才标记为 `human_verified`。

未实际核验的记录保持待复核状态，不为了展示人工参与而虚构审核结果。

## AI 与人工的分工

### AI 辅助

- 候选关系初步整理
- 检索关键词生成
- JSON 数据结构生成
- API / CLI / 测试代码辅助
- README 和研究文档初稿

### 人工负责

- 判断关系是否成立
- 判断关系类型和方向
- 核对原始证据
- 判断证据是否足够支持当前结论
- 调整 confidence
- 决定关系是否进入主数据集

因此，本项目采用 Human-in-the-loop 的研究流程，而不是直接把模型生成结果作为事实数据库。
